# Echoes of The Crypt

Compiler :

 ./gradlew lwjgl3:dist

Executer : 

(Windows) \n
java -jar '.\lwjgl3\build\libs\Echoes of The Crypt-1.0.0.jar' \n
java -jar '.\lwjgl3\build\libs\Echoes of The Crypt-1.0.0.jar' .\assets\maps\level1.tmx \n

Pour les autres OS, même fonctionnement que Windows, juste la façon d'utiliser les chemins diffèrent.
